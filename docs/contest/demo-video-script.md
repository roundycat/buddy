# 시연 영상 대본 (제출용 2~5분 · 투표용 1분)

> 배포된 시제품에서 `scripts/demo/record-demo.mjs`로 자동 녹화하고 `scripts/demo/compose.mjs`로 편집합니다(방법: `scripts/demo/README.md`).
> 녹화할 때마다 새 아이(만 14세 미만)·보호자 계정을 가입시켜, 가족이 처음 쓰는 순서(가입 → 초대 코드 → 보호자 동의 → 사용)를 그대로 보여 줍니다. 심사 계정(`judge-…`)은 쓰지 않습니다. 심사위원이 처음 보는 상태로 남겨 두어야 합니다.
> 영상이 투표 페이지에 공개될 수 있으므로, 위기 메시지는 화면에 나타나기 전부터 흐리게 가리고 끝에 상담 전화 109를 넣습니다.

## 투표용 1분 (1080×1920 세로, `VOTE`)
`docs/contest/vote-campaign.md`의 표를 따릅니다: 밤 10시 질문 → 친구·대화 → 흐리게 가린 위기 메시지와 도움 버튼 → "웃겨 죽는 줄ㅋㅋ"은 평소 대화 → 보호자에게는 사실만 → 사람 연결 미션 → 투표 부탁과 109.

## 찍기 전 확인
- 배포 주소에서 `/api/health`가 응답하는지, Claude API 키가 들어가 있는지 확인합니다(키가 없으면 미리 정한 답장으로 대신 답해 영상이 어색해집니다).
- 첫 로그인 직후에는 보호자 화면의 요약·감정 흐름이 비어 있을 수 있습니다. 녹화 스크립트는 같은 흐름 안에서 대화·모험을 먼저 만든 뒤 보호자 화면을 찍습니다.
- 배경 음악은 저작권 없는 음원만 씁니다. 실제 환아 사진과 병원 로고는 쓰지 않습니다.
- 다 만든 뒤 한 번 끝까지 보고, 아이 메시지가 흐림 없이 보이는 프레임이 없는지 확인합니다.
