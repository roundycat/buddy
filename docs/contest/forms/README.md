# 제출 양식 (성과보고서 · 참가신청서)

KEIT가 배포한 「(Word양식) 2026 AI 라이프 솔루션 챌린지 성과보고서」(`template.docx`, 글자 조각만 합친 원본)에 보고서 본문을 채워 넣습니다.

```bash
python3 docs/contest/forms/build_forms.py   # out/ 의 두 Word 파일과 ../report-draft.md 를 다시 만듦
docs/contest/forms/preview.sh               # (선택) LibreOffice로 PDF를 만들어 쪽수 확인
```

- 본문은 `report_content.py` 한 곳에서 고칩니다. `**굵게**`, `^{1}`(위첨자 출처 번호), `[ ]`(채울 칸, 양식에서 노란색)을 씁니다.
- 성과보고서는 **2쪽 이내**입니다. 고친 뒤에는 Word에서 열어 2쪽인지 꼭 확인하세요. `preview.sh`는 맑은 고딕 대신 줄 간격이 조금 더 큰 Noto Sans CJK로 그리므로, 여기서 2쪽이면 Word에서도 대개 2쪽 안에 들어갑니다.
- 참가신청서는 표에서 이름(과 대표 소속)만 채웁니다. 생년월일·휴대전화·이메일, 개인정보 동의 체크, 날짜, 대표 서명은 각자 직접 채웁니다(서명은 자필 또는 전자서명 필수).

## 제출 전에 채울 칸
| 칸 | 채우는 때 |
|---|---|
| 위기 140문장 지표 3줄과 해석 | 팀원 위기 문장 → `EVAL_SET=heldout` 측정 후 |
| 시제품 주소 | Render 배포 후 |

역할·보호자 설문·전문가 자문은 자료가 없어 넣지 않았습니다. 생기면 `report_content.py`에 줄을 더합니다.
