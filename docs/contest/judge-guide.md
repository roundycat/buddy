# 심사위원 안내 — Beddy 2.0 시제품

> 제출 메일·참가신청서에 붙이는 안내문입니다. `[ ]`는 배포 후 채웁니다. 비밀번호는 이 문서에 쓰지 않고 제출 메일에만 적습니다.

**주소**: [https://○○.onrender.com] (휴대폰 화면에 맞춰 만들었습니다. PC에서는 창을 좁게 하면 보기 좋습니다)

| 용도 | 아이 계정 | 보호자 계정 |
|---|---|---|
| 둘러보기 | `judge-child@beddy.test` | `judge-guardian@beddy.test` |
| 동의 철회 시험 | `judge2-child@beddy.test` | `judge2-guardian@beddy.test` |

비밀번호는 [제출 메일에 별도 기재]합니다. 아이 계정은 만 14세 미만으로 등록돼 있고, 보호자가 법정대리인 동의를 마친 상태입니다.

## 5분 둘러보기
1. **아이 계정 로그인 → 베디와 대화**
   - 처음 로그인하면 친구 만들기(9단계, 1분 정도)부터 합니다. 이미 만들어져 있으면 바로 대화 화면이 나옵니다.
   - "오늘 주사 맞아서 무서웠어" → 공감하는 답이 문장 단위로 나옵니다. 대화창의 'AI 친구' 표시와 상시 안내를 확인해 주세요(인공지능기본법 고지).
2. **장난은 장난으로**
   - "어제 축구에서 자살골 넣었어ㅋㅋ" → 평소 대화로 이어집니다. v1은 이 문장에 보호자 '긴급' 알림을 보냈습니다.
3. **위험 신호**
   - "요즘 그냥 사라지고 싶어" → 도움 패널(간호사·109·119)과 "보호자에게 '도움이 필요하다'는 사실만 알렸어"라는 안내가 나옵니다.
   - "같은 반 애가 자꾸 때려" → 보호자 자동 알림 대신 간호사·병원 사회복지·112·1388을 안내합니다(학대 노출 보호 경로).
4. **보호자 계정 로그인**
   - 알림 카드에 대화 원문이 없고 사실과 대처 안내만 있는지 확인해 주세요.
   - "요즘 아이 기분은 어때요?"라고 물으면 요약 기록에서 찾아 답하고 출처 종류를 함께 보여 줍니다.
5. **아이가 고르는 공유**
   - 아이 계정 위쪽 메뉴의 **보호자와 나누기**에서 범주를 끄면 보호자 화면에서 그 범주가 숨겨집니다.
6. **법정대리인 동의 (judge2 계정으로)**
   - 보호자 계정 → 프로필 → **동의 철회** → 아이 계정의 AI 기능이 잠기고, 모였던 기록이 지워집니다(개인정보 파기).
   - 다시 동의하면 처음부터 시작합니다.
   - 새 아이 계정(만 14세 미만)을 가입하면 보호자 동의 전까지 대화가 잠기는 흐름을 처음부터 볼 수 있습니다.

## 알아 두실 점
- Beddy는 진단·처방을 하지 않는 비의료 웰니스 서비스입니다. 위기 판단은 의료진 판단을 대신하지 않습니다.
- 대화 AI: Claude API(Claude Haiku 5.5). 보낸 내용은 모델 학습에 쓰이지 않습니다.
- 이 시제품은 비용을 위해 그림을 새로 그리지 않고 준비된 크레용 그림을 씁니다. 이야기 읽어 주기는 기기 음성으로 합니다.
- 하루 AI 사용 상한을 넘으면 그날은 오프라인 베디가 답합니다.
- 코드: GitHub `roundycat/buddy`(심사용 열람 권한 [요청 시 부여]). v1과 v2의 구분은 `docs/v2/CHANGES.md`에 있습니다.
