Beddy는 입원 중인 아이가 AI 친구와 이야기하고, 보호자는 대화 원문이 아닌 요약만 받는 서비스입니다. 이번에는 아이에게 안전한 AI를 만드는 데 집중하고 있습니다.

- 보호자에게는 "도움이 필요하다"는 사실만 알리며, 학대 노출은 보호자에게 자동으로 보내지 않고 간호사·사회복지 선생님·112·1388로 안내하고

바쁘시겠지만 15분 정도 아래 질문 가운데 편한 것만 의견을 주시면 큰 도움이 됩니다. 이름과 소속을 보고서에 밝혀도 되는지, 익명("소아청소년과 전문의 A")으로 할지도 알려 주세요.

2. 위기 단계별 대응(긴급·위험은 보호자에게 최소 알림 / 관찰은 알림 없이 아이에게 먼저 묻기 / 학대 노출은 병원 안 어른으로 안내)이 현장 관점에서 적절한가요? 빠진 경로가 있을까요?
3. 병원에서 이런 서비스를 쓴다면 신호를 누가(간호사실, 사회복지팀, 주치의) 받아야 할까요?
4. 아이가 AI 친구에게 지나치게 기대지 않도록 하려면 무엇이 더 필요할까요?
5. 보호자에게 무엇을 보여 주고 무엇을 감춰야 아이의 신뢰를 지킬 수 있을까요?
