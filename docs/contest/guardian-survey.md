# 보호자 설문 (구글 설문지로 옮기기용)

- 대상: 자녀를 키우는 보호자 (자녀 입원 경험이 있으면 더 좋음)
- 목표: **10월 28일(화)까지 30명 이상**
- 익명. 이름·연락처·자녀 병명은 받지 않습니다.
- 첫 화면 안내문: "장기 입원 아동을 위한 AI 정서 동행 서비스 'Beddy 2.0'을 준비하는 대학생 팀입니다. 응답은 익명이며 대회 보고서의 통계로만 씁니다. 3분 걸립니다."

## 문항

1. 자녀가 1주 이상 입원한 적이 있나요? (예 / 아니요)
2. 자녀 나이 (만 8세 이하 / 9~13세 / 14~18세)
3. 자녀가 입원해 있을 때(또는 입원한다면) 아이의 마음 상태를 얼마나 걱정하나요? (1 전혀 아니다 ~ 5 매우 그렇다)
4. 아이가 힘든 마음을 보호자에게 말하지 않고 혼자 견딘다고 느낀 적이 있나요? (1~5)
5. 아이가 AI 친구와 나눈 대화를 보호자가 어디까지 보면 좋겠나요?
   - 대화 원문 전부 / 하루 요약만 / 위험할 때만 알림 / 아이가 고른 것만 / 보고 싶지 않다
6. 아이가 "죽고 싶다" 같은 말을 AI에게 했을 때 보호자에게 알려야 한다면, 무엇을 받고 싶나요?
   - 대화 원문 / "도움이 필요하다"는 사실과 대처 안내 / 알림 없이 의료진에게만 / 잘 모르겠다
7. 아래 안전장치 중 가장 중요한 것 2개를 골라 주세요.
   - 위기 신호 감지와 즉시 도움 연결 / 진단·처방을 하지 않음 / 대화 원문 비공개 / AI라는 사실을 숨기지 않음 / AI에 의존하지 않게 사람과 이어 줌 / 학대가 의심될 때 보호자 대신 병원·기관으로 안내
8. 안전장치가 위와 같다면 자녀에게 Beddy를 쓰게 할 의향이 있나요? (1~5)
9. 하고 싶은 말 (자유 응답, 선택)

## 결과 정리 (보고서용)
- 응답 수, 입원 경험 비율
- 문항 3·4·8의 평균, 4~5점 비율
- 문항 5·6·7 선택 비율 (상위 2개)
- 인용할 자유 응답 1~2개 (개인 식별 내용 제거)
