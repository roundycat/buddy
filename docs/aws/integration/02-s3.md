# Migration Report — Amazon S3

**Date:** 2026-08-06  
**Status:** Complete (bucket-gated)

## Before

Binary assets written under `.data/avatars`, `.data/photos`, etc.

## After

`createBlobStore` (`src/backend/shared/persist/blob-store.ts`):

| Asset | S3 key pattern |
|-------|----------------|
| Avatars | `avatars/{user}.png`, `avatars/{user}__c{n}.png` |
| Photos | `photos/{userId}/{photoId}` |
| Schedule images | `schedule-images/{itemId}.png` |
| Diary | `diary/...` |
| Storybook art | `storybooks/...` |
| Parent letter photo | `storybook-parent-letters/...` |
| KB summary objects | `kb-summaries/{childUserId}/...` |

When `AVATAR_S3_BUCKET` is unset → local disk fallback (dev).

## Env

```
AVATAR_S3_BUCKET=...
AVATAR_S3_REGION=us-east-1   # optional; defaults to AWS_REGION
```

## Metrics

`S3WriteErrors`, `S3ReadErrors`, `StorageErrors` via CloudWatch namespace `Beddy`.

## UX

Same image URLs (`/api/...` proxies); no client redesign.
